# Эксперимент по тензорному ускорению на Raspberry Pi 5

Этот каталог содержит **протокол** и **микробенчмарк**, а не численные результаты исследования. На текущем компьютере нет подтверждённого Pi 5 + Coral: время устройства здесь не измерялось.

1. Прочитайте [методику и правила интерпретации](./PROTOCOL.md) и [черновик рукописи](../../docs/16_TENSOR_ACCELERATION_MANUSCRIPT.md).
2. На Pi 5 установите совместимые `numpy`, `tflite_runtime`, `pycoral` и драйвер Coral, проверьте `edgetpu.list_edge_tpus()`. Версии и контрольные суммы моделей запишите.
3. Подготовьте **одинаковые** квантованные входные тензоры для обоих исполнителей в локальном `.npy` (формы из протокола); не коммитьте лица и модели.
4. Запустите `benchmark.py` на Pi 5 с парой INT8-моделей; программа требует реальный PCIe TPU, при его отсутствии не подменяет второй режим CPU. `--synthetic` использовать **только** как проверку инструмента.
5. Результаты окажутся в игнорируемом каталоге `results/`: `runs.csv`, `manifest.json`, `output_comparison.json`. Проверить корректность и только после этого включать обезличенные сводные числа в работу.

```bash
python3 -m unittest discover -s research/tensor_acceleration -p 'test_*.py'
python3 research/tensor_acceleration/benchmark.py --help
```

**Границы инструмента:** замеряет только `set_tensor`, `invoke`, `get_tensor`. Никакой декодировки изображения, детекции лиц как задачи (postprocess + аннотации), оценки качества или измерения электрической мощности в нём пока нет. Для утверждения об ускорении **полной системы** понадобится отдельная серия по протоколу. Нельзя превращать время этого микробенчмарка в измеренный FPS камеры.
