# Практический план запуска — с чего начать, чтобы заработало

> Цель: за 5-6 недель получить рабочий офлайн гараж, а не красивый диплом. Начинаем с самого критичного и простого.

## Принцип: снизу вверх, от скелета к мозгу

Не начинай с FaceID и Astra — это самое сложное. Начни с того, что даст видимый результат за 2 дня и на чем все остальное держится.

```
Фаза 0: Подготовка (1 день)
Фаза 1: Скелет Pi4 + Pi5 + MQTT + 1 датчик (3 дня) -> уже видишь графики
Фаза 2: Безопасность — газ + реле + отпечаток (7 дней) -> гараж уже безопасен
Фаза 3: Зрение — Coral + Face + Radar (10 дней) -> умный доступ
Фаза 4: Голос Astra — STT Pi5 + TTS Pi4 (7 дней) -> говорит
Фаза 5: Автономность — AP, RTC, UPS, тесты (5 дней) -> полностью офлайн
```

### ФАЗА 0: Подготовка (сегодня-завтра)

**Что сделать:**
1.  Собрать железо на столе, не в гараже: Pi4, Pi5 с Coral (твой уже работает), 1x ESP32, BME280, провода
2.  Прошить SD карты: Raspberry Pi OS Lite 64-bit на обе
3.  На Pi5 проверить Coral: `ls /dev/apex_0 && python3 -c "from pycoral.utils import edgetpu; print(edgetpu.list_edge_tpus())"` — должен показать pci
4.  Соединить Pi4 <-> Pi5 прямым Ethernet кабелем, задать статику:
    - Pi4 eth0: 10.0.0.1/24
    - Pi5 eth0: 10.0.0.2/24
    - `ping 10.0.0.1` с Pi5
5.  Заказать недостающее: если нет — BME280, MQ-7, R503, LD2450, реле 4ch, DS3231 x2, сирена 12В

**Результат:** 2 Pi видят друг друга, Coral работает.

### ФАЗА 1: Скелет — сервер и первый датчик (3-4 дня)

**Это самое важное. Без этого ничего не заработает.**

**На Pi4 (10.0.0.1) — SERVER:**
```bash
# 1. Docker
curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER

# 2. Клонируешь репу
git clone https://github.com/Gr1n95/smart_home.git
cd smart_home

# 3. Поднимаешь только Mosquitto
docker compose -f docker-compose.pi4.yml up -d mosquitto

# 4. Проверяешь
mosquitto_pub -h localhost -t test -m hello
mosquitto_sub -h localhost -t test
```

**На Pi5 (10.0.0.2) — проверка связи:**
```bash
mosquitto_pub -h 10.0.0.1 -t garage/test -m "Pi5 online"
# На Pi4 должен прийти
```

**ESP32 + BME280:**
- Ставишь ESPHome на ноут, прошиваешь ESP32 YAML с BME280 -> WiFi к GarageNet (пока к домашнему WiFi)
- ESP публикует в `garage/climate/temp` на 10.0.0.1
- На Pi4 поднимаешь InfluxDB + Grafana из `docker-compose.pi4.yml`
- Настраиваешь Grafana datasource Influx, видишь график температуры

**Результат Фазы 1:** Телефон -> GarageNet -> Grafana показывает температуру. Скелет жив. Уже можно показывать.

### ФАЗА 2: Безопасность — газ и доступ по пальцу (7 дней)

**Почему сейчас:** газ — это жизнь. Отпечаток — проще лица, даст рабочий СКУД за 1 день.

**Газ:**
1.  Подключить MQ-7 к ESP32 (ADC pin), прогрев 48ч (включи и оставь)
2.  Калибровка: на чистом воздухе замерить Ro
3.  Логика в `backend/app/main.py` на Pi4: если CO > 50ppm -> `garage/actuator/fan ON` + сирена
4.  Подключить реле 4ch к Pi4 GPIO: реле1=вытяжка, реле2=свет, реле3=сирена
5.  Тест: поднести зажигалку без огня (газ) — сирена орет, вентилятор включается

**Отпечаток R503 (самый быстрый доступ):**
1.  Подключить R503 к Pi5 via USB-UART (/dev/ttyUSB0)
2.  На Pi5 запустить `fingerprint_service` — регистрация пальца
3.  MQTT `garage/access/finger/result` -> Pi4 -> `garage/actuator/lock OPEN`
4.  Подключить электромагнитный замок к реле Pi4
5.  Тест: палец -> замок щелкает

**Результат Фазы 2:** Гараж уже безопасен: газ ловит, дверь открывается по пальцу, свет по реле. Можно ставить в гараж.

### ФАЗА 3: Зрение — Coral + Face + Radar (10 дней)

**Теперь тяжелое, но у тебя Coral уже работает.**

**Шаг 3.1 — Coral + Frigate (1 день):**
- На Pi5 `docker compose -f docker-compose.pi5.yml up -d frigate`
- Frigate config уже в `frigate/config.yml` с `detector: coral pci:0`
- PiCam3 NoIR -> Frigate -> детекция person 12ms
- MQTT `garage/security/person` -> Pi4

**Шаг 3.2 — FaceID с Coral (3-4 дня):**
- Скачать `blazeface_128x128_edgetpu.tflite` в `coral_models/`
- Запустить `services/face/coral_face_detector.py` на Pi5
- Зарегистрировать 2-3 лица: скрипт делает 10 фото с разных ракурсов -> эмбеддинги в `faces_db.npz`
- Тест: подходишь -> Coral детектит 25ms -> Pi4 открывает если лицо знакомое

**Шаг 3.3 — Radar LD2450 (2 дня):**
- Подключить LD2450 к Pi5 UART (/dev/ttyAMA0)
- Запустить `radar_service` — публикует `garage/security/radar {count, x,y}`
- Настроить зоны в гараже: вход, верстак
- Логика Pi4: если radar count=0 10 мин -> свет OFF

**Результат Фазы 3:** Подходишь к гаражу — радар включает ИК подсветку, Coral находит лицо 25ms, Astra говорит "Привет", замок открывается. Вау-эффект готов.

### ФАЗА 4: Голос Astra — STT Pi5 + TTS Pi4 (7 дней)

**Почему после зрения:** голос зависит от MQTT и Pi4 сервера, которые уже работают.

**Шаг 4.1 — STT на Pi5 (тяжелое):**
- На Pi5: `docker compose -f docker-compose.pi5.yml up -d whisper openwakeword`
- Whisper small ru — скачать модель заранее (150MB)
- ReSpeaker 2-Mics -> openWakeWord "Астра" (пока hey_jarvis) -> Whisper -> текст
- Тест: говоришь "привет" -> в логах текст

**Шаг 4.2 — Astra Core на Pi4 (логика):**
- На Pi4: запустить `services/astra/astra_core.py`
- Подключить колонку 3W к Pi4 (jack)
- Piper TTS `ru_RU-irina-medium` — скачать .onnx
- Тест: Pi5 публикует `astra/stt/text "включи свет"` -> Pi4 Astra парсит интент -> `garage/actuator/light ON` -> говорит "Включаю свет"

**Шаг 4.3 — Интеграция:**
- Обучить wake word "Астра" (20 записей голоса)
- Добавить интент "что с газом", "какая температура"
- Проактивность: CO >50 -> Astra сама говорит

**Результат Фазы 4:** Говоришь "Астра, включи свет" -> свет включается, Astra отвечает голосом. Полностью офлайн.

---

### ФАЗА 5: Автономность и тесты (5 дней)

**Теперь делаем из прототипа на столе — систему в гараже.**

1.  **WiFi AP GarageNet на Pi4:** hostapd + dnsmasq, телефон подключается без интернета, открывает HA `http://192.168.4.1:8123`
2.  **RTC DS3231** на оба Pi: `dtoverlay=i2c-rtc,ds3231`, время не плывет без инета
3.  **UPS HAT** + скрипт graceful shutdown
4.  **Корпуса IP55**, WAGO, кабель-менеджмент, 12В шина
5.  **Тесты:**
    - Выдернуть Ethernet Pi5 — Pi4 должен продолжать газ/отпечаток
    - Вырубить свет — UPS держит, сирена пищит
    - Тест FaceID: очки, шапка, темнота с ИК
    - Тест газа: баллончик
    - Нагрузочный: 1 человек + голос + Frigate — CPU Pi4 <40%, Pi5 <60% с Coral

**Результат Фазы 5:** Система в гараже, работает без интернета, с сиреной, с Astra.
