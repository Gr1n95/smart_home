## 2. Уровни системы

### Уровень 0: Железо (Edge)
- **Контроллеры:** ESP32-WROOM-32E (2-3 штуки). Почему не ESP8266? Нужен BLE, больше ног, стабильнее.
- **Протоколы:** I2C для BME280/BH1750 (до 50см провод), UART для радара и отпечатка, WiFi для связи с центром.
- **Питание:** 12В шина по гаражу -> DC-DC 5В/3.3В на каждом узле. Резерв: LiFePO4 12В 6Ач + BMS.

### Уровень 1: Транспорт
- **MQTT** — главный. Топики: `garage/climate/temp`, `garage/security/radar/count`, `garage/access/face/result`
- Брокер: Mosquitto на Pi.
- QoS 1 для критичных (газ, доступ).

### Уровень 2: Мозг (Raspberry Pi 5)
Докер-композ:

```yaml
services:
  mosquitto: # брокер
  homeassistant: # логика, автоматизации, UI
  influxdb: # хранение телеметрии
  grafana: # графики
  frigate: # опционально, для камер и детекции
  backend:
    build: ./backend # твой Python FastAPI - СКУД, радар, газовая логика
  whisper: # STT
  piper: # TTS
  ollama: # LLM локально
```

### Уровень 3: Логика регулирования (PID + Правила)
- **Температура:** Если <5°C -> включить конвектор (реле). Если >30°C -> вытяжка. Гистерезис 2°C чтобы не щелкать.
- **Влажность:** Если >75% -> осушитель/вытяжка. Если <20% зимой — не критично.
- **Газ:** MQ-7 CO > 50ppm -> АЛАРМ: включить вытяжку на 100%, открыть ворота (если есть привод), уведомление в Telegram, сирена, отключить зарядку авто.
- **Свет:** BH1750 < 50 lux + радар видит человека -> включить свет на 5 мин. День + никого — выключить.

### Уровень 4: Доступ
Пайплайн:
1. Человек подходит -> радар LD2450 триггерит -> включает ИК подсветку и камеру.
2. Параллельно: R503 ждет палец.
3. Face Recognition: 
   - Захват кадра -> InsightFace / face_recognition (dlib) -> эмбеддинг 512-d -> сравнение с базой в SQLite (порог 0.45)
   - Liveness: проверка моргания / depth / ИК блик. Простейший — попросить повернуть голову.
4. Логика: (Лицо == OK) AND (Палец == OK) -> открыть замок. Или (Лицо == OK) OR (Палец == OK) если настроено как 1 из 2.
5. Замок: электромагнитный 12В 300кг + реле + кнопка выхода изнутри + механический ключ (обязательно!).

### Уровень 5: Голосовой ассистент
Два режима:

**A) Яндекс Алиса (облако):**
- Делаешь навык в Yandex Dialogs.
- Pi прикидывается устройством умного дома Яндекса через MQTT (yandex2mqtt).
- Команды: "Алиса, что в гараже?", "Открой ворота".

**B) Локальный (офлайн, приватный):**
- Mic: ReSpeaker 2-Mics Pi HAT (с шумодавом)
- STT: faster-whisper (small-модель, русский)
- Wake Word: openWakeWord / "Алиса" / "Гараж"
- NLU: Home Assistant Assist + LLM (Ollama llama3.1:8b) для свободных фраз
- TTS: Piper (голос ru_RU)
- Логика: "Включи свет" -> HA intent -> MQTT -> реле

Рекомендую гибрид: локальный всегда, Алиса как дополнение.

## 3. База данных
- InfluxDB для временных рядов (температура каждые 10с)
- SQLite/Postgres для событий: кто зашел, когда сработал газ, фото с камеры
- Хранение биометрии: только эмбеддинги, не фото! Шифровать.

## 4. Безопасность
- Отдельный VLAN / WiFi для IoT
- WireGuard VPN для доступа извне, никаких пробросов портов
- Fail2ban на Pi
- Логирование всех доступов
- Кнопка "Паника" — обесточить все кроме света
