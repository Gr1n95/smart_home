# Архитектура v2: Полностью автономный гараж на 2x Pi (без интернета)

> Твоя идея с двумя Pi — 100% правильная. Один Pi5 вытянет, но будет на грани и с лагами. Делим на Infrastructure и AI.

## Почему 1x Pi5 не хватит для офлайна

В онлайне часть задач уходит в облако (STT/TTS/LLM). В офлайне все на CPU:

| Задача | Нагрузка на Pi5 | RAM |
|---|---|---|
| Home Assistant + MQTT + Influx | 15% CPU, 600MB | норм |
| InsightFace buffalo_l (1 кадр) | 80-100% 1 ядра ~0.8 сек | 500MB |
| Faster-Whisper small ru (3 сек речи) | 100% 4 ядра ~1.5 сек | 1GB |
| Piper TTS | 20% ~0.3 сек | 100MB |
| Ollama phi3:mini 3.8B Q4 | 300% CPU, 2-3 токена/сек | 2.8GB |
| Frigate 1 камера 1080p детекция | 40-60% постоянно | 400MB |

Итого если одновременно: человек подошел (FaceID) + сказал "включи свет" (Whisper+LLM) — Pi5 уйдет в своп и HA зависнет. А HA не должен виснуть, когда у тебя утечка CO.

**Решение: разделить критичное и тяжелое.**

## Новая схема

```
                    ГАРАЖНАЯ СЕТЬ (без интернета)
                    WiFi AP: GarageNet (hostapd на Pi4)
                    Ethernet: прямой кабель Pi4<->Pi5 1Gbps
                              192.168.4.0/24

┌──────────────────────────────────────────────────────────────────────┐
│  Pi4 - HOME BRAIN (192.168.4.2) - КРИТИЧНЫЙ, ВСЕГДА ВКЛЮЧЕН          │
│  Роль: Выживание гаража                                              │
│  Железо: DS3231 RTC, UPS HAT, реле, Ethernet                         │
│  Софт (легкий, стабильный):                                          │
│   - Mosquitto MQTT (брокер главный)                                  │
│   - Home Assistant Core                                              │
│   - InfluxDB + Grafana (графики)                                     │
│   - Node-RED / FastAPI regulator (газ, климат, свет)                 │
│   - hostapd + dnsmasq (раздает WiFi GarageNet, портал)               │
│   - WireGuard НЕ нужен (нет инета), но можно для локального VPN      │
│  Приоритет: RT, watchdog, автоперезапуск. Если Pi5 сдох — газ и замок│
│             все равно работают!                                      │
└───────────────────────┬──────────────────────────────────────────────┘
                        │ MQTT, HTTP API
                        │ Ethernet кабель (рекомендую) или WiFi
┌───────────────────────▼──────────────────────────────────────────────┐
│  Pi5 - AI BRAIN (192.168.4.1) - ТЯЖЕЛЫЙ, МОЖНО ПЕРЕЗАГРУЖАТЬ          │
│  Роль: Глаза и уши                                                   │
│  Железо: PiCam3 NoIR + ИК прожектор, R503, LD2450, ReSpeaker 2-Mics, │
│          опционально Hailo-8L AI HAT (27 TOPS) или Coral USB         │
│  Софт (тяжелый, bursty):                                             │
│   - face_service (InsightFace buffalo_s, 320x320 для скорости)       │
│   - fingerprint_service (R503)                                       │
│   - radar_service (LD2450)                                           │
│   - voice_assistant:                                                 │
│       openWakeWord (hey_jarvis) -> faster-whisper small/tiny ru     │
│       -> HA Intent + Ollama phi3:mini -> Piper ru                    │
│   - Frigate (опционально, 1 камера)                                  │
│  При падении: Pi4 детектит по MQTT Last Will и шлет сирену           │
└──────────────────────────────────────────────────────────────────────┘
         │              │              │              │
      [ESP32-1]      [ESP32-2]      [Реле 4ch]    [Телефон]
      BME280+MQ      BH1750+геркон  Свет/Вытяжка  Подкл. к GarageNet
                                                  http://192.168.4.2:8123
```

## Распределение нагрузки — цифры

**Pi4 (4GB достаточно):**
- CPU idle 5-10%, при тревоге 30%
- RAM ~1.2GB занято
- SD: только система, база на USB SSD

**Pi5 (8GB обязательно):**
- Idle 10%
- При распознавании лица: 1.5 сек пик 100%
- При голосе: 2-3 сек пик 400%
- RAM: 4.5GB занято (с LLM), без LLM ~1.5GB
- Если поставишь Hailo-8L HAT (~70€) — FaceID ускорится в 10 раз до 0.08 сек, Whisper тоже можно на Hailo.

## Офлайн-специфика — что надо доделать

### 1. Время и сеть
Без интернета нет NTP. Время поплывет, логи и сертификаты сломаются.
- **Купи 2x DS3231 RTC модуль I2C** (по 3€). Подключить к обоим Pi. Настроить `dtoverlay=i2c-rtc,ds3231`
- Pi4 поднимает WiFi AP:
  ```bash
  # hostapd
  ssid=GarageNet
  wpa_passphrase=что-то_длинное
  channel=6
  # dnsmasq - раздает 192.168.4.10-100
  ```
- Телефон подключается к GarageNet -> открывает HA `http://192.168.4.2:8123` без интернета.

### 2. Голосовой ассистент полностью офлайн
Забудь про Яндекс Алису — без инета она мертва. Делаем локальную:

**Пайплайн:**
```
ReSpeaker (ALSA) -> VAD Silero (отсекает тишину) -> openWakeWord ("привет гараж" - надо обучить)
-> запись 5 сек -> faster-whisper small ru (модель 150MB, скачать заранее) -> текст
-> HA Assist: "включи свет" -> intent -> MQTT garage/actuator/light ON
-> если не понял: Ollama phi3:mini (3.8B) -> "что такое угарный газ?" -> ответ
-> Piper TTS (голос irina-medium, 60MB) -> aplay на колонку
```

**Модели скачать ЗАРАНЕЕ на ноуте и перенести на флешке:**
- `whisper small ru`: `small` или `tiny` если Pi4 слабый
- `piper ru_RU-irina-medium`
- `phi3:mini-4k-instruct-q4_K_M.gguf` (2.2GB) — самый оптимальный для Pi5. Не бери llama3 8B — не вытянет.
- `buffalo_s` для InsightFace (40MB)

### 3. Обновления без интернета
- Сделать скрипт `offline-update.sh` — с флешки ставит docker образы
- Все docker образы сохранить заранее: `docker save -o images.tar ...`

### 4. Уведомления без Telegram
Telegram без инета не работает. Замена:
- Сирена 12В 110дБ в гараже при CO > 70ppm
- Лампа-стробоскоп красная
- Локальные пуши в HA app когда телефон подключен к GarageNet (HA умеет локальные пуши)
- Зуммер на Pi4

### 5. Безопасность офлайна
Плюс: никто из инета не взломает. Минус: если украдут Pi — украдут базу лиц.
- Шифрование диска Pi4 (LUKS) с ключом на флешке
- Хранить только эмбеддинги, не фото
- Логи на отдельной флешке, которую можно выдернуть

## Проводка между Pi

**Рекомендую прямой Ethernet кабель** (патч-корд 1м). Надежнее WiFi, 1Gbps, низкая задержка для MQTT.

Настройка статики:
- Pi4: `192.168.4.2/24`, `eth0` + `wlan0` AP `192.168.4.1`? Нет, лучше:
  - Pi4 `eth0: 10.0.0.1`, `wlan0: 192.168.4.1` (AP)
  - Pi5 `eth0: 10.0.0.2` подключен к Pi4, `wlan0: клиент GarageNet 192.168.4.2`
- Или проще: оба в одном свитче 5 портов за 15€.

## Итог: тянет ли 1 Pi5? 
Да, но с компромиссами:
- Без LLM, только команды HA (не болталка)
- Whisper tiny вместо small (хуже понимает)
- FaceID раз в 2 секунды, а не видео поток
- Без Frigate

С двумя Pi — работает комфортно, и есть резервирование: если AI Pi5 завис — Pi4 все равно откроет ворота по отпечатку и включит вытяжку по газу. Это правильно для гаража.
