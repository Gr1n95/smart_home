### Рекомендация по замку (выбран электромеханический)
- **Электромагнитный НЕ брать** для гаража на улице: он fail-safe — пропало питание → открыт. Офлайн-система + ворота без света = открыто для всех.
- **Электромеханический** (fail-secure): пропало питание → закрыт, изнутри открывается всегда механикой/кнопкой, снаружи аварийный механический ключ. Пример: Cisa 11610-50 (~45€) или электромеханическая защёлка на дверь/калитку (~20-30€).
- Если секционные ворота с приводом: СКУД даёт разрешение -> реле замыкает вход привода, замок не нужен на сами ворота.

### Политика многофакторности (3 категории факторов)
| Режим | Факторы | Сценарий |
|---|---|---|
| Стандарт | лицо **ИЛИ** отпечаток | день, свои, руки/лицо свободны |
| Усиленный | биометрия **И** (NFC **ИЛИ** PIN) | ночь, режим охраны |
| Деградация | NFC **И** PIN | зима/балаклава/маска, отказ биометрии |
| Гость | NFC + одноразовый PIN | временный доступ, лог в MQTT |

> NFC-защита: голый UID у RC522 подделывается magic-картами, поэтому NFC-UID проверяется белым списком на Pi4 **в паре** со вторым фактором. Для диплома можно упомянуть MIFARE DESFire как промышленный вариант.

## Почему обычная камера и USB-микрофон (решение)

**Камера — обычная, не NoIR.** NoIR + ИК-прожектор нужны только для невидимого ночного режима. Вместо этого:
- Темнота → радар LD2450 видит движение → свет включается → обычная камера видит лицо → доступ. Задержка +200-300 мс, на практике незаметно.
- Минус: ночью при подъезде ощутимо включается свет. Если задолбает — докупается NoIR камера + ИК-прожектор (~50€), обычная камеру с ИК не работает из-за фильтра.
- USB webcam проще в подключении чем PiCam (V4L2 /dev/video0, не нужен libcamera в Docker для Frigate) — рекомендую для старта USB webcam.

**Микрофон — USB, не ReSpeaker.** ReSpeaker (линейка + beamforming) нужен для wake word «Астра» с 3-5 метров сквозь шум вытяжки. Это апгрейд удобства, не необходимость:
- Рабочий сценарий без линейки: подошёл → FaceID/отпечаток открыл → Astra активна на 10-15 сек → сказал команду с 0.5-1 м. Надёжно и бесплатно.
- Wake word через openWakeWord оставляем как эксперимент (модель hey_jarvis → Astra), но ожидания по USB-микрофону низкие: сработает вблизи, в тихом гараже.
- Альтернатива активации: кнопка на стене / активация по отпечатку — вообще без микрофонных проблем.

**Итог экономии:** ~40€ (NoIR+ИК+ReSpeaker → обычная камера+USB-микрофон), а главный сценарий «подъехал → узнали → открыли → сказал команду» работает так же.
