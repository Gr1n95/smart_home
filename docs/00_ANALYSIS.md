# Анализ задачи: Умный гараж

## Что ты хочешь — моими словами
Это не просто "датчики в гараж". Это 4 системы в одной коробке:

1.  **SCADA для гаража** — сбор телеметрии (T/H, газ, свет) + управление климатом и светом.
2.  **Охранно-трекинговая система** — радар видит людей, даже если они не двигаются.
3.  **СКУД (контроль доступа)** — два фактора: лицо + отпечаток. Должен работать в -15°C, в темноте, в пыли.
4.  **Голосовой ассистент** — локальная Алиса, которая понимает "открой ворота", "какая загазованность".

### Мое мнение: где сложность

**Задача РЕАЛЬНА, но это уровень дипломного проекта / стартапа, а не "поставить датчик за выходные".** 
Главная ошибка новичков — вешать все на один Raspberry Pi по I2C проводами по всему гаражу.

Правильная архитектура — распределенная:

```
[Датчики] -> [ESP32-узлы] --MQTT/WiFi--> [Raspberry Pi 5 - Мозг] <---> [Исполнители]
                                      |
                              [Home Assistant / Custom Backend]
                                      |
                              [Алиса / Локальный ассистент]
```

**Топ-3 самых сложных узла:**

1.  **Радар и трекинг людей.** Дешевый RCWL-0516 — это просто "кто-то есть". Тебе нужен mmWave. LD2410 — видит 1 человека и его дистанцию. LD2450 / HLK-LD6001 — уже трекает до 3 человек с координатами X,Y. Но в гараже с металлом будут отражения. Придется калибровать.
2.  **FaceID в гараже.** PiCam в темноте слепнет. Нужна ИК-подсветка + NoIR камера + liveness detection, иначе откроют по фото с телефона. На улице зимой лицо в шапке/балаклаве — будет отказ. Поэтому отпечаток как второй фактор обязателен, а не опция.
3.  **Газ.** MQ-сенсоры дешевые, но дрейфуют от температуры и требуют прогрева 24ч и калибровки. В гараже надо ловить CO (выхлоп), LPG/пропан, метан. Один MQ-2 не закроет. Нужен комплекс: MQ-7 для CO + MQ-135 для качества воздуха + датчик дыма. И главное — действие при тревоге: включить вытяжку, открыть ворота, вырубить розетки, отправить в Telegram, а не просто пищать.

**Что я бы сделал по-другому, чем обычно советуют:**

- Не использовать DHT11/DHT22. В гараже они умрут за полгода. Только BME280 / SHT31 в корпусе с мембраной.
- Не делать "свой умный дом с нуля на Flask". Взять Home Assistant OS как базу. 80% логики (автоматизации, графики, MQTT) уже готово. А твой кастомный код — как аддоны.
- Ассистента делать гибридным: Yandex Alice для облачных команд (если интернет есть), и локальный Whisper + Piper + LLM (Ollama с Llama 3) для офлайна. Иначе в гараже без интернета ты останешься без голоса.
- Питание: обязательно UPS на 12В + LiFePO4. При отключении света гараж должен закрыть ворота и отправить "свет пропал".

**Оценка по времени и деньгам (для DE):**

- **BOM Бюджетный вариант:** 180-250€ (Pi 4 + LD2410 + BME280 + BH1750 + MQ-7 + R503 + PiCam v3 + реле)
- **Pro вариант:** 400-600€ (Pi 5 8GB + LD2450 + SHT31 + MH-Z19C + ReSpeaker Mic Array + NoIR cam + нормальный щиток)
- **Время:** MVP за 2-3 недели (датчики + MQTT + HA). Полный комплекс с СКУД и радаром + голосом — 2-3 месяца вечерами.

Вывод: начинай с ядра (Pi + MQTT + 1 ESP32 с BME280) и наращивай. Не пытайся спаять все сразу.
