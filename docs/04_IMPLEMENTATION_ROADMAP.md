# Дорожная карта — пошагово на 8 недель

## Неделя 0: Подготовка
- [ ] Нарисовать план гаража с размерами, где щиток, ворота, розетки
- [ ] Проверить WiFi в гараже (если слабо — протянуть витую пару или поставить AP)
- [ ] Заказать BOM (см. 02_HARDWARE_BOM.md). Пока едет — ставить софт.

## Неделя 1: Ядро
Цель: Pi + MQTT + первый датчик
- [ ] Установить Raspberry Pi OS Lite 64-bit, Docker, Mosquitto, Home Assistant Container
- [ ] Поднять `docker-compose.yml` (mosquitto, influxdb, grafana)
- [ ] Прошить ESP32 с BME280, подключить к MQTT, увидеть графики в Grafana
- [ ] Сделать Telegram бота который шлет температуру каждый час

Результат: ты уже видишь климат гаража с телефона.

## Неделя 2: Климат и газ
- [ ] Добавить BH1750 + MQ-7 + MQ-135 на второй ESP32
- [ ] Калибровка MQ: 48ч прогрев, замерить Ro на улице
- [ ] Подключить реле 4-канальное, вентилятор, лампу
- [ ] Написать автоматизации: 
  - Если CO > 50ppm -> вентилятор ON + Telegram ALARM
  - Если темно + движение (пока PIR) -> свет ON
- [ ] Протестировать газ (осторожно!)

## Неделя 3: Радар
- [ ] Подключить LD2450 к ESP32 (UART)
- [ ] Настроить зоны: зона входа, зона верстака, зона авто
- [ ] Визуализация в HA: карта с точками людей
- [ ] Логика: считать людей в гараже, если 0 >10мин — выключить свет/отопление
- [ ] Калибровка под металл: поставить экран из фольги за радаром

## Неделя 4: СКУД — железо
- [ ] Установить короб IP65 у двери, протянуть 12В и Ethernet к Pi
- [ ] Монтаж R503 (врезать в стену/короб), PiCam NoIR + ИК прожектор
- [ ] Монтаж электромагнита, кнопки выхода
- [ ] Проверка: палец открывает, камера видит ночью

## Неделя 5: СКУД — софт
- [ ] Написать `face_service.py`: регистрация лиц (скрипт делает 10 фото с разных ракурсов)
- [ ] База лиц: 2-3 человека
- [ ] Интеграция: face + fingerprint -> MQTT `garage/access/grant`
- [ ] Логика анти-брутфорс: 5 неудач -> блок 5 мин + фото в Telegram
- [ ] Тест liveness: попробовать фото на телефоне, распечатка

## Неделя 6: Голосовой ассистент
- [ ] Установить ReSpeaker, проверить запись `arecord`
- [ ] Поставить faster-whisper, piper, openWakeWord
- [ ] Интеграция с HA Assist: команды "включи свет", "какая температура", "открой ворота"
- [ ] Добавить кастомные intents: "что с газом", "кто был в гараже"
- [ ] Опционально: навык Яндекс Алисы через yandex2mqtt

## Неделя 7: Безопасность и автономность
- [ ] UPS + скрипт graceful shutdown

- [ ] Пожарный тест: что будет если сгорит ESP32? Система должна перейти в безопасный режим (вентилятор ON, замок закрыт)
- [ ] Сделать кнопку "Отпуск" — усиленный мониторинг

- Учет электроэнергии (PZEM-004T)

## Частые ошибки
1.  Питать все от Pi 5В — сгорит. Только отдельная 12В шина.
2.  Ставить MQ в углу у пола — CO легче воздуха? На самом деле CO ~ как воздух, ставь на высоте 1.5м. LPG тяжелее — у пола.
3.  Не делать механический ключ — останешься на улице когда Pi зависнет.
4.  Писать свой FaceID с нуля — бери готовый InsightFace.
